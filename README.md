# Классические шифры и криптоанализ

Учебный проект на C++: консольная программа, которая шифрует и расшифровывает текст пятью классическими шифрами и взламывает два из них без знания ключа.

## Возможности

| Пункт меню | Что делает |
| --- | --- |
| 1 | Шифр перестановки по столбцам: шифрование и расшифрование |
| 2 | Шифр Бофора: шифрование и расшифрование |
| 3 | Шифр Плейфера: шифрование и расшифрование |
| 4 | Шифр ADFGX: шифрование и расшифрование |
| 5 | Шифр Бифида: шифрование и расшифрование |
| 6 | Взлом шифра перестановки по столбцам полным перебором |
| 7 | Взлом шифра Бофора методом Касиски |

## Сборка

Проект собирается только под Windows, потому что использует `windows.h` для настройки кодировки консоли. Нужны CMake 3.14 или новее и компилятор с поддержкой C++17, например MinGW из MSYS2.

```bash
git clone https://github.com/Maxim07S/Project_2_2026_Python.git
cd Project_2_2026_Python
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
```

Кладите проект в папку без пробелов и кириллицы в пути, например `C:\dev\crypto`: иначе сборка может завершиться ошибкой.

## Запуск

```bash
build\crypto.exe
```

Программа показывает меню и ждёт номер пункта. Пункт `0` завершает работу.

### Шифрование и расшифрование (пункты 1–5)

1. Выберите режим: `1` — зашифровать, `2` — расшифровать.
2. Введите путь к текстовому файлу с исходным текстом.
3. Введите ключ.
4. Введите путь к файлу, куда сохранить результат.

Для шифра ADFGX программа дополнительно спросит алфавит из 25 букв для таблицы. Введите `1`, чтобы взять стандартный латинский алфавит без `j`.

Перед обработкой текст приводится к нижнему регистру, и в нём остаются только латинские буквы `a–z`. Пробелы, цифры, знаки препинания и кириллица отбрасываются.

### Криптоанализ (пункты 6–7)

Шифртекст вводится прямо в консоли одной строкой без пробелов, только строчными латинскими буквами.

## Как работает криптоанализ

### Взлом перестановки по столбцам

1. Программа перебирает длины ключа от 2 до 8.
2. Для каждой длины она перебирает все перестановки столбцов и расшифровывает текст.
3. Каждый вариант получает оценку: сумму весов частых английских триграмм (`the`, `and`, `ing` и других), которые в нём встретились.
4. На экран выводятся длина ключа, порядок столбцов и текст с наибольшей оценкой.

Всего проверяется 46 232 варианта ключа.

### Взлом шифра Бофора методом Касиски

1. Программа ищет в шифртексте повторяющиеся триграммы и считает расстояния между ними.
2. Для длин от 2 до 19 она считает, сколько расстояний делится на эту длину. Самая частая длина принимается за длину ключа.
3. Шифртекст делится на группы: в одну группу попадают буквы, зашифрованные одной буквой ключа.
4. Для каждой группы перебираются 26 сдвигов. Выбирается тот, при котором частоты букв ближе всего к частотам английского языка.
5. Найденные сдвиги складываются в ключ, который выводится на экран.

Метод надёжно работает на длинных текстах: на коротком шифртексте повторов мало, и длина ключа может определиться неверно.

## Тесты

```bash
ctest --test-dir build --output-on-failure
```

В проекте 11 тестов на Doctest. Они проверяют позитивные, граничные и негативные сценарии для таких функций:

- построение гаммы и шифр Бофора;
- разбиение текста на биграммы и ключевая матрица шифра Плейфера;
- шифрование и расшифрование перестановкой по столбцам.

Шифры ADFGX и Бифида и функции криптоанализа тестами пока не покрыты.

## Ограничения

- Программа работает только с английским текстом и только под Windows.
- В шифрах Плейфера, ADFGX и Бифида буква `j` заменяется на `i`, поэтому после расшифрования исходная `j` не восстанавливается.
- Шифр Плейфера вставляет `x` между одинаковыми буквами и в конец текста нечётной длины. При расшифровании эти буквы остаются в тексте.
- Алфавит для ADFGX не проверяется: он должен содержать ровно 25 разных букв.
- Функция оценки текста по частотам букв `score_text_6` заимствована и помечена в коде.
